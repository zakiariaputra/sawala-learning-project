# 03. Object & Array

Materi minggu 1-2 — struktur data `Object`, `Array`, dan `Array of Objects` di JavaScript untuk mengelola sekumpulan data.

## Yang Dipelajari

- **Object**: Membuat objek dengan pasangan key-value, mengakses properti, dan mengubah nilai properti (misal: `siswa.nilai`)
- **Array**: Membuat himpunan data berurutan dan mengakses elemen menggunakan indeks berbasis nol (`[0]`, `[1]`, dst.)
- **Array of Objects**: Menggabungkan array dan objek untuk menyimpan daftar data terstruktur (misal: `daftarSiswa`)
- Penggunaan template literals (`` `${}` ``) untuk menampilkan data terstruktur secara rapi

## Cara Menjalankan

```bash
node index.js
```

## Catatan

- Indeks array di JavaScript dimulai dari angka `0` (zero-indexed)
- Properti pada `Object` dapat diakses dan diubah nilainya menggunakan dot notation (misal: `siswa.nilai = 90`)
