# 02. Kondisi & Function

Materi minggu 1-2 — pengkondisian (`if-else`) dan pembuatan fungsi (`function`) untuk logika validasi data di JavaScript.

## Yang Dipelajari

- Pengkondisian bercabang (`if`, `else if`, `else`) untuk validasi rentang nilai dan kehadiran
- Operator logika (`&&`, `||`) untuk evaluasi kondisi majemuk
- Pembuatan dan pemanggilan fungsi (`function`) dengan parameter dan nilai kembalian (`return`)
- Penggabungan logika kondisi dan fungsi untuk sistem penilaian serta validasi status kelulusan siswa

## Cara Menjalankan

```bash
node index.js
```
## Catatan

- Operator `||` (OR) mengevaluasi ke `true` bila salah satu kondisi terpenuhi (digunakan untuk cek batas nilai/kehadiran yang tidak valid)
- Operator `&&` (AND) mengevaluasi ke `true` hanya bila semua kondisi terpenuhi (digunakan pada fungsi `cekKelulusan`)
