# 01. Variabel & Tipe Data

Materi minggu 1-2 — pengenalan variabel (`const`, `let`) dan seluruh tipe data primitif di JavaScript, plus object.

## Yang Dipelajari

- Deklarasi variabel: `const` vs `let`
- Tipe data primitif: `string`, `number`, `boolean`, `bigint`, `undefined`, `null`, `symbol`
- Tipe data non-primitif: `object`
- Konversi tipe data ke string (`String()`) untuk keperluan `console.log`

## Cara Menjalankan

```bash
node index.js
```

## Catatan

- `Symbol` tidak bisa langsung digabung pakai operator `+`, harus dikonversi dulu pakai `String()`
- `BigInt` dideklarasikan dengan akhiran `n` pada literal angka
